# Threadleaf 0.1.0

This is Threadleaf's first stable public-source release. It is an AGPL-licensed, local-first desktop
workspace for opening existing Markdown vaults without conversion. The public release is Linux
x86_64 only.

## What is ready

- Source, Live Preview, and Reading modes over canonical Markdown files.
- Two independently editable panes, persistent tabs, pinned notes, history, quick switching, and
  keyboard-remappable commands.
- Recovery-backed note, property, task, attachment, rename, move, trash, and restore operations.
- Search, tags, aliases, links, backlinks, outline, graph, daily notes, templates, JSON Canvas, and
  standalone HTML export.
- Explicit trusted-plugin compatibility with exact-version evidence for the workflows listed in
  the generated compatibility registry.
- A headless CLI backed by the same vault kernel as the desktop application.
- Offline operation with no account or background update check.

## Linux downloads

The release contains an unsigned x86_64 AppImage, an unsigned x86_64 RPM, one checksum file for
those packages, and a normalized reproducible application archive with its complete file manifest
and checksum.

Verify the native packages before running them:

```sh
sha256sum -c Threadleaf-0.1.0-linux-x86_64.sha256
chmod +x Threadleaf-0.1.0-linux-x86_64.AppImage
./Threadleaf-0.1.0-linux-x86_64.AppImage
```

Or install the RPM on Fedora-compatible systems:

```sh
sudo dnf install ./Threadleaf-0.1.0-linux-x86_64.rpm
```

## Evidence

The release commit passes `pnpm check`, the packaged Electron first-run and writable-vault gates,
the complete packaged attachment workflow, the visual matrix, the theme and deuteranomaly matrix,
native package inspection, and the reproducible-tree comparison. Compatibility claims remain bound
to the exact versions and executable workflows in
[`docs/compatibility/registry.md`](../compatibility/registry.md).

## Known boundaries

- The public Linux artifacts are unsigned. The checksum proves file identity, not
  publisher identity.
- Native CI verifies macOS and Windows contributor packages, but they remain unpublished until
  signing and notarization gates pass.
- Threadleaf has no mobile client or hosted sync service.
- Community-plugin compatibility is reported per exact plugin version and workflow, not claimed
  across the full Obsidian ecosystem.
- Live Preview preserves unsupported or ambiguous Markdown as visible source. It does not yet offer
  complete first-class editing for every table, math, diagram, raw HTML, or large-document shape.
- Keep an ordinary external backup as normal local-first practice.
