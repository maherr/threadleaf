# Support and feedback

Threadleaf can save a privacy-safe Markdown support bundle from Settings > About and updates or the
Save privacy-safe support bundle command in Ctrl/Cmd+K. Nothing is uploaded. Review the generated
file, add the human details below, and share it only when you choose.

The generated diagnostics are aggregate-only. They exclude note and attachment content, names and
paths, vault names and identifiers, hashes, plugin identities and settings, raw errors, usernames,
hostnames, network addresses, and locale. Screenshots are separate and may contain note text, so
review them independently.
