01 · ORIENTATION

One source, two audiences

Normative requirements use MUST or MUST NOT and are eligible for conformance. Informative notes explain scope, provenance, or a gap. A passing row always names the exact app release and an executable gate.

Consumers can validate the JSON datasets and run the linked fixtures without Electron, an account, or a network connection. The rendered tables below are generated from those same datasets.

Compatibility levels
  1. L0, discovered. A valid manifest and bounded bundle were found.
  2. L1, loaded. The bundle evaluated and an instance was constructed.
  3. L2, activated. onload completed without an uncaught error.
  4. L3, integrated. Named commands, events, views, or processors registered.
  5. L4, workflow verified. A named workflow passed end to end.

Private data boundary

Contributors MUST remove private vault bytes, credentials, copied application assets, and network-derived output. Unsupported cases remain visible rather than being made to pass.

Contribution requirements

The Excalidraw corpus includes a pinned official Obsidian round-trip record with observed status. It retains exact identities, digests, isolation facts, behavior, and limitations without treating external evidence as an executable corpus pass.
