03 · VOCABULARY

Compatibility API vocabulary

IdentifierLabelMeaningSource
Compatibility levels
  1. L0, discovered. A valid manifest and bounded bundle were found.
  2. L1, loaded. The bundle evaluated and an instance was constructed.
  3. L2, activated. onload completed without an uncaught error.
  4. L3, integrated. Named commands, events, views, or processors registered.
  5. L4, workflow verified. A named workflow passed end to end.
