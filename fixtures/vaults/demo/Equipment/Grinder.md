# Grinder

A conical burr grinder with stepped settings from fine to extra coarse. Every method in
[[Brewing/Grind Size Guide]] assumes this grinder's numbering, which will not match a different
model exactly.

## Maintenance

- [ ] Brush out retained grounds weekly
- [ ] Deep clean with grinder cleaning tablets monthly
- [x] Re-check the zero point after the last burr clean
